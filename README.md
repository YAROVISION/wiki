# Довідник граф звітності

Інтерактивний вебдовідник для спрощення та автоматизації процесу заповнення форм звітності про виконання заходів АП в Установі та її територіальних органах.

---

## 🎯 Мета проєкту

Головна мета проєкту — надати фахівцям зручний, швидкий та інтуїтивно зрозумілий інструмент для роботи з вимогами щодо заповнення звітності (згідно з Додатком 1 до АП). 

Додаток розв'язує такі завдання:
* **Швидка навігація**: Миттєвий пошук потрібної графи в XLSX-файлах за її літерою (наприклад, `A`, `B`, `C`...) або ключовими словами.
* **Чіткі інструкції**: Надання детальних офіційних роз'яснень щодо того, які саме дані (текстовий звіт, кількість перевірок, логічні «так/ні») та на основі яких документів мають бути внесені до відповідної графи.
* **Зниження кількості помилок**: Інформація структурована за звітними періодами (1-е та 2-е півріччя) з чітким розмежуванням вимог до кожної графи.

---

## 🛠️ Функціонал додатку

* **Панель статистики (Dashboard)**: Відображає загальну кількість граф у звітному файлі та деталізацію за періодами (1-е та 2-е півріччя).
* **Гнучкий пошук та фільтрація**:
  * Пошуковий рядок з автодоповненням та підсвічуванням збігів у тексті.
  * Швидка фільтрація за періодами звітності (Всі графи, 1-е півріччя, 2-е півріччя).
* **Два режими відображення**:
  * **Плитка (картки)**: Зручна сітка по дві картки в ряд (з адаптивним переходом в один стовпчик на мобільних пристроях).
  * **Таблиця**: Класичний лінійний вигляд для швидкого сканування великого обсягу інформації.
* **Детальний модальний перегляд**: При виборі графи відкривається деталізоване вікно з повною інформацією про період звітності, опис заходу та інструкцію для заповнення.
* **Швидке копіювання**: Можливість копіювання опису заходу або всієї інформації про графу в буфер обміну в один клік.
* **Двоколірна тема оформлення**: Підтримка темного та світлого режимів інтерфейсу зі збереженням налаштувань.
* **Адаптивний мобільний інтерфейс**: Зручне використання з мобільних пристроїв завдяки оптимізованій висоті хедера та гнучкій сітці.

## 🎨 Дизайн-система та технології

Проєкт реалізовано на базі кастомної дизайн-системи **Exchanger Coffee Design System**:
* **Естетика**: Теплі та глибокі кавові відтінки еспресо, лате та вершків з високим рівнем контрастності для легкого читання.
* **Шрифти**: Використовується виключно моноширинний шрифт **JetBrains Mono** для створення атмосфери професійного терміналу.
* **Технологічний стек**:
  * **HTML5**: Семантична та доступна розмітка.
  * **Vanilla CSS**: Чисті CSS-змінні, CSS Grid та Flexbox для гнучкого макетування без використання сторонніх фреймворків.
  * **Javascript (ES6+)**: Динамічне рендерення даних, фільтрація в реальному часі та обробка інтерфейсних подій.
  * **FontAwesome**: Набір іконок для візуального кодування інформації.

## 🚀 Як запустити локально

Проєкт є статичним додатком (Single Page Application) і не потребує складної інсталяції чи серверних баз даних:
1. Завантажте або склонуйте репозиторій.
2. Відкрийте файл `index.html` у будь-якому сучасному веббраузері або запустіть через локальний сервер (наприклад, за допомогою розширення Live Server у VS Code чи команди `python -m http.server 8000`).
